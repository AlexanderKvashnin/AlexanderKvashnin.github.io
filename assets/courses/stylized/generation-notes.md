## Shared prompt

Use case: style-transfer. Asset type: a wide 16:9 course-card illustration for a professional computational materials science laboratory website. Input image 1 is the existing COURSE illustration to restyle and supplies the visual concept. Input image 2 is an approved PROJECT illustration used only as a STYLE reference. Match image 2's pale off-white #f8fafc background, matte softly shaded 3D spheres, clean fine rods, gentle ambient shadows and restrained slate blue, desaturated teal, blue-grey and muted ochre palette. Preserve the course-specific concept rather than copying the reference lattice. Make a complete centered composition occupying about 75 percent of the frame, generous pale margins, readable even at 200x120 pixels. No neon, glossy reflections, dramatic glow, textured backgrounds, text, equations, chemical labels, logos or watermark.
